# Threads Tone & Style Guide

## Principles

- **Concise**: lead with the point, cut filler
- **Informative**: the reader should take something away
- **Natural**: should not read like a bot

## Post Format

```
{emoji} {2~3 line summary}

🔗 {source URL}

#{hashtag1} #{hashtag2} #{hashtag3}
```

## Emoji Guide

- 🔧 Tools / libraries
- 🚀 Performance / releases
- 🔐 Security
- 🤖 AI / ML
- 💡 Concepts / tips
- 📦 Packages / deployment

## Hashtag Rules

- Maximum 3 hashtags
- Avoid generic tags (#dev, #IT)
- Use specific, topic-relevant tags (#Python #OpenSource #WebDev)

## Prohibited

- Sensationalist language ("shocking", "game-changer", "unbelievable")
- Repeating the same hashtags across posts
- Exceeding 500 characters
